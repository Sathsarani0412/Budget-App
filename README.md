# Budget App

## Overview

Budget App is a personal finance management application developed using Flutter and SQLite. The application helps users track their income and expenses, monitor spending habits, and gain insights into their financial activities through an easy-to-use and responsive interface.

## Features

### User Authentication

* User Registration (Sign Up)
* Secure Login
* Forgot Password Functionality

### Dashboard

The dashboard provides a quick overview of financial information, including:

* Total Income
* Total Expenses
* Recent Transactions
* Financial Summary

### Income Management

Users can:

* Add Income Records
* View Income History
* Manage Financial Entries

### Expense Management

Users can:

* Add Expense Records
* Track Daily Spending
* View Expense History

### Analytics

The analytics section provides visual insights into financial activities, helping users understand:

* Income Distribution
* Expense Trends
* Spending Patterns
* Financial Performance

### Profile Management

Users can:

* View Profile Information
* Update Personal Details
* Manage Account Settings

### Navigation

The application includes a bottom navigation bar for easy access to:

* Dashboard
* Add Income/Expense
* Analytics
* Profile

## Technologies Used

* Flutter
* Dart
* SQLite

## Database Functionality

SQLite is used to store:

* User Information
* Income Records
* Expense Records
* Financial Transactions

## System Features

### Financial Tracking

Allows users to maintain accurate records of income and expenses.

### Data Persistence

All financial records are stored locally using SQLite for efficient data management.

### Analytics Dashboard

Provides users with visual summaries and financial insights.

### User-Friendly Interface

Designed with a clean and intuitive interface to improve usability and accessibility.

## Project Purpose

This project was developed to demonstrate mobile application development using Flutter, database integration with SQLite, user authentication, financial record management, and data visualization concepts.
